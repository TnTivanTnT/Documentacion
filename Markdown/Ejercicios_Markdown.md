# Ejercicios Prácticos - Markdown

> 📚 [Volver al Índice de Documentación](../README.md)

Este documento contiene ejercicios prácticos para dominar la escritura en Markdown.

---

## Nivel Principiante

### Sección 1: Sintaxis Básica
#### Ejercicio 1.1: Crear documento
Crea un archivo llamado `practica_basica.md` que use negritas, cursivas y tachados en un solo párrafo.

---

### Sección 2: Estructura y Listas
#### Ejercicio 2.1: Tutorial paso a paso
Crea un documento que explique cómo hacer un café, usando una lista ordenada y sub-listas no ordenadas para los ingredientes.

---

### Sección 3: Enlaces e Imágenes
#### Ejercicio 3.1: Directorio de recursos
Crea una lista de tus 3 sitios web favoritos usando enlaces inline y enlaces de referencia. Añade un logo al final.

---

## Nivel Intermedio

### Sección 1: Bloques de Código
#### Ejercicio 1.1: Comparación de lenguajes
Crea dos bloques de código (Python y Bash) que impriman "Hola Mundo", asegurando que el resaltado de sintaxis sea correcto.

---

### Sección 2: Tablas
#### Ejercicio 2.1: Comparativa de Sistemas Operativos
Crea una tabla que compare Windows, Linux y macOS en 3 categorías (Kernel, Precio, Licencia), usando alineación centrada para las columnas.

---

### Sección 3: Citas y Notas
#### Ejercicio 3.1: Glosario de términos
Crea una lista de definición con 3 términos de informática (ej: Algoritmo, API, Framework) y añade una nota al pie en el primer término.

---

## Nivel Avanzado

### Sección 1: HTML y GFM
#### Ejercicio 1.1: Componentes avanzados
Crea un bloque expandible (`<details>`) que oculte una tabla compleja o un fragmento de código largo.

#### Ejercicio 1.2: Insignias de Proyecto
Busca en [Shields.io](https://shields.io/) y genera 3 insignias para un proyecto ficticio (ej: Version, License, Status).

---

### Sección 2: Obsidian y Diagramas
#### Ejercicio 2.1: Flujo de trabajo
Crea un diagrama Mermaid (`graph TD`) que represente los pasos para estudiar un examen.

---

## Ejercicio Final Integrador

### Proyecto: README Profesional de Software

Crea un archivo `README.md` completo para una aplicación ficticia de gestión de tareas (To-Do List) que incluya:

1. **Insignias** en la parte superior.
2. **Título y Descripción** clara.
3. **Tabla de Contenidos** con enlaces internos.
4. **Guía de Instalación** con bloques de código.
5. **Ejemplo de Uso** con capturas (placeholders) o bloques de código.
6. **Tabla de Características** principales.
7. **Sección de Preguntas Frecuentes** usando `> [!info]` o `<details>`.
8. **Instrucciones para Contribuir**.
9. **Licencia** del proyecto.

Usa toda la potencia de Markdown: jerarquía de encabezados, tablas, listas de tareas, énfasis y bloques de código.
